# Images Directory

This directory contains image assets for the Trail Guardian app.

## Current Images:
- `adaptive-icon.png` - Adaptive app icon for Android
- `favicon.png` - Web favicon
- `icon.png` - Main app icon
- `splash-icon.png` - Splash screen icon

## Adding New Images:

### Forest/Nature Images:
Place landscape and nature photos here for backgrounds and UI elements.

### User Interface Images:
- Logos and branding assets
- Icon sets and graphics
- Illustrations

### Guidelines:
1. Use descriptive names: `forest-background.jpg`, `trail-marker-icon.png`
2. Include multiple resolutions when needed: `@2x`, `@3x` suffixes
3. Optimize images for mobile (WebP format recommended)
4. Keep file sizes reasonable for mobile apps

### Example Forest Background:
The WelcomeScreen currently uses a remote Unsplash image. For production, 
download and include a local forest background image here.
